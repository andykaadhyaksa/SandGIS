SANDGIS — PAKET PWA (bisa diinstal di HP)
==========================================
Isi folder:
  index.html            aplikasi SandGIS (sudah termasuk menu Survey)
  manifest.webmanifest  data aplikasi (nama, ikon, tampilan)
  sw.js                 service worker (cache agar bisa dibuka tanpa internet)
  icons/                ikon aplikasi

WAJIB diunggah SEMUA file & folder ini ke hosting HTTPS. Jangan hanya index.html.

OPSI A - Netlify (paling mudah, tanpa akun GitHub)
  1. Buka app.netlify.com/drop  (daftar gratis bila diminta)
  2. Seret SELURUH folder ini ke halaman tersebut
  3. Anda mendapat alamat https://nama-acak.netlify.app  (bisa diganti di Site settings)

OPSI B - GitHub Pages
  1. Buat repository baru (publik), unggah semua file & folder ini ke branch main
  2. Settings > Pages > Source: Deploy from a branch > main / (root) > Save
  3. Alamat: https://USERNAME.github.io/NAMA-REPO/

MEMASANG DI HP
  Android (Chrome): buka alamat https tadi > menu titik tiga > "Instal aplikasi" / "Tambahkan ke layar utama"
                    (atau tab Setting > Instal Aplikasi di dalam SandGIS)
  iPhone (Safari) : buka alamat > tombol Bagikan > "Tambah ke Layar Utama"

CATATAN
  - Izin GPS (menu Survey) hanya muncul bila dibuka lewat https:// - alamat hosting di atas sudah https.
  - Pertama kali dibuka butuh internet agar pustaka (Leaflet, dll.) ter-cache. Setelah itu program bisa dibuka offline;
    peta dasar, peta mini foto, dan alamat foto tetap butuh internet.
  - Data survey tersimpan di HP per alamat web. Jika alamat diganti, datanya terpisah - ekspor dulu (Survey > Atur > ZIP).
  - Memperbarui aplikasi: ganti index.html di hosting, lalu ubah VERSION di sw.js (mis. sandgis-v2) agar HP mengambil versi baru.
